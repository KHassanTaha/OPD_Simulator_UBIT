Each section below is written by one command:
  dotnet run --project src/OpdSimulator.Cli -- validate --lambda 0.5 --mu 0.8 --model M/M/c --horizon 200000 --out /tmp/mmc.txt
  dotnet run --project src/OpdSimulator.Cli -- validate --lambda 0.5 --mu 0.8 --ca2 1 --cs2 2 --model M/G/c --horizon 200000 --out /tmp/mgc.txt

VALIDATION REPORT — simulated vs analytical closed-form queueing model
================================================================

Reproduce this report:
  dotnet run --project src/OpdSimulator.Cli -- validate --lambda 0.5 --mu 0.8 --servers 1 --horizon 200000 --seed 42 --ca2 1 --cs2 1 --model M/M/c

Configuration
-------------
  arrival rate λ        : 0.5 per minute
  arrival variability   : exponential (Poisson) (Ca² = 1)
  service rate μ        : 0.8 per minute per server
  servers c             : 1
  service variability   : exponential (Cs² = 1)
  simulated horizon     : 200000 minutes
  random seed           : 42
  analytical model      : M/M/c — Erlang-C (exact)

Steady-state check
------------------
  operating minutes     : 200000
  threshold             : 100000
  traffic intensity ρ   : 0.625

Comparison
----------
  metric                          simulated     analytical        Δ%
  average wait in queue Wq         2.1393         2.0833      2.69
  average queue length  Lq         1.0696         1.0417      2.69

Verdict
-------
  mode                  : validation — the run sampled the distributions the
                          analytical model describes (Ca² and Cs² above)
  tolerance             : 5% on both Wq and Lq
  result                : PASS

Notes
-----
  - Closed-form values are steady-state results; they describe the long-run
    behaviour, not one clinic day. A 165-minute session is transient.
  - M/M/c is exact (Erlang-C). M/G/c uses Allen–Cunneen (exact
    Pollaczek–Khinchine at c = 1). G/G/c uses Allen–Cunneen (exact
    Kingman at c = 1). The two compound models are approximations for
    c > 1, so their 5% gate checks the simulator against the approximation,
    not against an exact answer.
  - A non-unit Ca² or Cs² is sampled from a Gamma distribution with shape
    1/C²; Ca² = 0 is sampled as Deterministic. The report names the family
    that was actually run.
